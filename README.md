# Tabla Periódica Interactiva

Página web interactiva con los 118 elementos de la tabla periódica.

## Qué incluye

- Los 118 elementos con número atómico, símbolo, nombre en español y masa atómica aproximada
- Buscador por nombre, símbolo o número atómico
- Filtros por categoría: no metales, metales alcalinos, alcalinotérreos, metales de transición, metales post-transición, metaloides, halógenos, gases nobles, lantánidos y actínidos
- Al tocar un elemento se muestra su detalle: categoría, grupo, periodo y masa atómica
- Diseño responsivo, sin dependencias

## Cómo verla

Abre `index.html` en el navegador, o visita el despliegue en Vercel.

## Tecnologías

HTML, CSS y JavaScript en un solo archivo.
